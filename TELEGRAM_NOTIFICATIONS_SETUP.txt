================================================================================
  COMO CONFIGURAR TELEGRAM
================================================================================

1. CRIAR BOT NO TELEGRAM:
   a) Abra Telegram e procure "@BotFather"
   b) Envie: /newbot
   c) Escolha nome para bot (ex: "GoldTradingBot")
   d) Escolha username (ex: "gold_trading_bot_XYZ")
   e) Copie o TOKEN que receber

2. OBTER CHAT ID:
   a) Crie um grupo no Telegram (ex: "GoldTrading")
   b) Convide seu bot para o grupo
   c) Envie qualquer mensagem no grupo
   d) Acesse: https://api.telegram.org/bot{SEU_TOKEN}/getUpdates
   e) Procure por "chat":{"id":-123456789} (seu chat_id)
   f) Copie o ID (com o "-" se tiver)

3. CONFIGURAR .env:
   TELEGRAM_ENABLED=true
   TELEGRAM_BOT_TOKEN=123456789:ABCDEFGHIJKLMNOPQRSTUVWXYZabcdef
   TELEGRAM_CHAT_ID=-123456789

4. TESTAR:
   python test_telegram.py

================================================================================
  METRICAS RASTREADAS
================================================================================

Total de trades:
  - Contagem de todas as operações SELL aberta no agent
  - Inclui vencedoras e perdedoras
  - Reseta a cada novo dia (00:00)

Total de vitorias:
  - Contagem de trades que fecharam com profit > 0
  - Calcula em tempo real

Total de derrotas:
  - Contagem de trades que fecharam com profit <= 0
  - Calcula em tempo real

Win rate (%):
  - (Vitorias / Total trades) * 100
  - Exemplo: 28 wins / 35 total = 80.0%
  - Emoji indica qualidade:
    • 🔥 se >= 75%
    • 👍 se >= 60%
    • ⚠️ se < 60%

Lucro/Prejuizo ($):
  - Soma de todos os profits de trades fechados
  - Acumula durante o dia
  - Emoji indica:
    • 💚 se positivo (ganho)
    • ❤️ se negativo (perda)
    • ⚪ se zero

Ganho médio:
  - Soma dos profits positivos / número de wins
  - Mostra quanto se ganha em média por vitória

Perda média:
  - Soma dos profits negativos / número de losses
  - Mostra quanto se perde em média por derrota
