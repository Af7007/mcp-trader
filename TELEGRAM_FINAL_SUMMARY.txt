================================================================================
  TIPOS DE NOTIFICACOES AGORA
================================================================================

TIPO 1: SINAL ABERTO
Quando um SELL é aberto:
  → Ticket, tipo, volume, entrada, TP, SL
  → Indicadores: RSI, MACD, Trend, ATR
  → Enviado IMEDIATAMENTE

TIPO 2: TRADE FECHADO
Quando um trade fecha (WIN ou LOSS):
  → Ticket, resultado (+/-), tipo, duração
  → Preços entrada/saída
  → Estatísticas do dia (lucro, win rate, streak)
  → Enviado IMEDIATAMENTE

TIPO 3: RESUMO PERIÓDICO
A cada ~1 minuto:
  → Estado do agent (analyzing/trading/hedging)
  → Posições abertas
  → Lucro da sessão
  → Estatísticas gerais
  → Indicadores técnicos
  → Enviado AUTOMATICAMENTE

TIPO 4: RESUMO DE METRICAS **[NOVO!]**
A cada 5 trades:
  → Total de trades (exato)
  → Total de vitorias (exato)
  → Total de derrotas (exato)
  → Win rate % (com emoji)
  → Lucro/prejuizo $ (com emoji)
  → Ganho/perda média
  → Preço atual
  → Formato visual com linhas separadoras
  → Enviado AUTOMATICAMENTE

TIPO 5: ALERTAS CRITICOS
Quando hedge ativa ou erro ocorre:
  → Alerta com emoji 🚨
  → Descrição do problema
  → Detalhes adicionais
  → Enviado IMEDIATAMENTE
