## 📞 Problemas?

### Sons não tocam
- Clique na página primeiro (política autoplay)
- Verifique arquivos estão na pasta correta
- Confirme nomes exatos (case-sensitive)
- Veja console do browser (F12)

### Sons muito altos/baixos
- Ajuste no código (`game_v2.js` linha 90-96)
- Mude `volume: 0.5` para 0.1-1.0

### Formato errado
- Converta para MP3
- Use https://online-audio-converter.com
