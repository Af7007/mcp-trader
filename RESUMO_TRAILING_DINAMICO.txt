================================================================================
FLUXO DE FUNCIONAMENTO
================================================================================

1. ABERTURA (RSI + MFI confirmam)
   Calcula SL: entrada x (1 - 1.5%)
   Calcula TP: entrada x (1 + 5.0%)
   Abre posicao com buy_market/sell_market
   Armazena SL/TP para referencia

2. LUCRO < 0.2%
   Apenas monitora (SL/TP inicial protege)

3. LUCRO = 0.2% => TRAILING ATIVADO
   Seta trailing_active = True
   Calcula novo SL para defender
   Atualiza SL via TRADE_ACTION_SLTP
   Log: "[INICIO] TRAILING ATIVADO!"

4. LUCRO > 0.3% => TRAILING SOBE
   Calcula novo trailing: lucro - 0.1%
   Calcula novo SL: defende novo trailing
   Atualiza SL via TRADE_ACTION_SLTP
   Log: "[SUBIDA] Trailing: 0.2% -> 0.3%"

5. LUCRO < TRAILING => STOP HIT
   Fecha posicao
   Registra lucro alcancado
   Log: "[PARADO] STOP ATIVADO!"
