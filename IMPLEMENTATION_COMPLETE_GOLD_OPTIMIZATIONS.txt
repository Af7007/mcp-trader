================================================================================
  DIAGRAMA DE FLUXO: COMO FUNCIONA AGORA
================================================================================

1. Usuario executa:
   uv run python src/agents/btc_hedge_agent.py XAUUSDm

2. Agent inicializa:
   - Detecta: is_gold = True
   - Aplica automaticamente:
     * target_profit = $3.5
     * only_sell = True
     * volume = 0.01
     * hedge_trigger = -$2.0
     * etc...
   - Log: "🏆 GOLD MODE ATIVADO - Otimizado para SELL consistente!"

3. Agent começa analise (a cada 30 segundos):
   - Calcula indicadores (RSI, MACD, BB, etc)
   - Chama analyze_signal()

4. analyze_signal() retorna:
   - Se criterios nao sao atendidos: 'NEUTRAL'
   - Se criteria sao atendidos: 'SELL' (BUY eh rejeitado)

5. open_position('SELL') eh chamado:
   - Verifica: signal == 'BUY' and only_sell=True? → REJEITA
   - Verifica: price > $4100? → REJEITA
   - Calcula: sl_distance = tp_distance (proporcional)
   - Abre posicao com TP=$3.5, SL proporcional

6. Posicao esta aberta:
   - Monitora ate TP ou SL
   - Se atingir -$2.0: Ativa HEDGE (posicao oposta)
   - HEDGE fecha rapido com $1.5 de ganho

7. Posicao fecha:
   - Registra no database
   - Continua monitorando proximas oportunidades
   - Logs mostram: "✅ Posição aberta", lucros/perdas, etc
