 ONDE ESTA O PROBLEMA
================================================================================

Linha de comando do Python tinha prioridade sobre o código!

argparse (Python argument parser) trabalha assim:

1. Código define: self.volume = 0.02
2. .bat passa: --volume 0.01
3. argparse pega: --volume 0.01
4. Envia para agente: volume=0.01
5. Agente recebe: self.volume = 0.01 (sobrescrito!)
