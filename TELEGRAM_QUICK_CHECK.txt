================================================================================
  CONFIGURAR TELEGRAM (2 MINUTOS)
================================================================================

1. Abra Telegram → procure @BotFather → /newbot → copie TOKEN

2. Copie este TOKEN no .env:
   TELEGRAM_BOT_TOKEN=seu_token_aqui

3. Crie grupo no Telegram, convide seu bot, envie mensagem

4. Acesse: https://api.telegram.org/bot{SEU_TOKEN}/getUpdates
   Copie o chat ID (número com "-" na frente)

5. Copie no .env:
   TELEGRAM_CHAT_ID=seu_chat_id_aqui

6. Certifique-se de:
   TELEGRAM_ENABLED=true
