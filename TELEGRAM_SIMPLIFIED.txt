================================================================================
  COMO USAR
================================================================================

Simplesmente configure Telegram normalmente:

1. Obtenha TELEGRAM_BOT_TOKEN de @BotFather
2. Obtenha TELEGRAM_CHAT_ID da API getUpdates
3. Configure em .env:
   TELEGRAM_ENABLED=true
   TELEGRAM_BOT_TOKEN=seu_token
   TELEGRAM_CHAT_ID=seu_chat_id

4. Inicie o agent:
   uv run python src/agents/btc_hedge_agent.py XAUUSDm

5. Monitore Telegram:
   - Verá sinal quando SELL abre
   - Verá resultado quando trade fecha
   - Nada mais!
