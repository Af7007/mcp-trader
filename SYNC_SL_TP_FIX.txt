================================================================================
  CORRECAO DA SINCRONIZACAO DE SL/TP COM O BANCO DE DADOS
================================================================================

PROBLEMA IDENTIFICADO:
  - MT5 NÃO ARMAZENA SL/TP nos deals (objeto TradeDeal não tem esses campos)
  - Quando trades eram sincronizados, SL/TP apareciam como $0.00
  - Isso impedia análise adequada das estratégias de stop loss e take profit

INVESTIGACAO:
  Script criado: inspecionar_deals.py
  Resultado: Confirmado que MT5 TradeDeal não possui campos 'sl' e 'tp'
  Todos os 56 deals analisados tinham sl=N/A e tp=N/A

SOLUCAO IMPLEMENTADA:

1. **Arquivo de Backup Persistente:**
   - Criado: backup_sl_tp.json (raiz do projeto)
   - Armazena SL/TP para cada ticket assim que a posição é aberta
   - Recupera os valores quando a posição fecha

2. **Novos Métodos em btc_hedge_agent.py:**

   a) save_sl_tp_backup(ticket, sl, tp):
      - Salva SL/TP em JSON quando posição é aberta
      - Chamado após cada posição normal (linha 548)
      - Chamado após cada posição de hedge (linha 687)
      - Formato: { "ticket": {"sl": X, "tp": Y, "timestamp": "..."} }

   b) load_sl_tp_from_backup(ticket):
      - Carrega SL/TP do backup quando posição fecha
      - Chamado em save_trade_to_db() se SL/TP estiverem zerados
      - Fallback se trade_info não tiver os valores

3. **Lógica de Recuperação em save_trade_to_db():**
   - Primeiro tenta obter SL/TP do trade_info
   - Se zerados, tenta recuperar do backup JSON
   - Se ainda zerados, fica zerado (última tentativa falhou)

FLUXO COMPLETO:

1. Posição aberta:
   - SL/TP calculados
   - Salvos em trades_today (memória)
   - Salvos em backup_sl_tp.json (persistente)
   ✅ SL/TP preservados!

2. Posição fechada:
   - Procura SL/TP em trade_info (memória)
   - Se não encontrar, busca do backup JSON
   - Salva no banco com valores corretos

3. Sincronização histórica:
   - sincronizar_trades.py também busca do backup
   - Melhora chances de recuperar SL/TP de trades antigos
