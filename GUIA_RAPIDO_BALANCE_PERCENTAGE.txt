================================================================================
 COMO FUNCIONA INTERNAMENTE
================================================================================

Quando um trade fecha:

1. Agent obtém balance da conta MT5:
   account_balance = $1,250.00

2. Agent calcula percentual:
   profit_percentage = (total_profit / balance) * 100
                     = ($27.50 / $1,250.00) * 100
                     = 2.20%

3. Agent envia para Telegram com ambos valores

4. Você recebe mensagem formatada com os 2 novos campos

================================================================================
 PERGUNTAS FREQUENTES
================================================================================

P: Por que o percentual mudou entre mensagens?
R: Porque a cada trade que fecha, o total_profit muda. Ex:
   - Depois de +$10: 1.0% de $1000
   - Depois de +$20: 2.0% de $1000
   - Depois de +$15 (SL): 1.5% de $1000

P: E se a banca diminuir durante o dia?
R: O percentual é sempre calculado sobre o balance atual:
   - Banca $1000, Lucro $20 = +2.0%
   - Banca diminui para $995 (outro agente/operacao), Lucro $20 = +2.01%

P: Quando aparece 🔥?
R: Quando o profit percentage >= 1.0%
   - +1.00% → 🔥
   - +1.50% → 🔥
   - +2.00% → 🔥

P: Quando aparece 📈?
R: Quando o profit percentage > 0% MAS < 1.0%
   - +0.10% → 📈
   - +0.50% → 📈
   - +0.99% → 📈

P: Quando aparece 📉?
R: Quando o profit percentage <= 0%
   - -1.00% → 📉
   - -0.50% → 📉
   -  0.00% → 📉
